# Project instructions

Read `harness.md` and `README.md` before editing this project.
Keep prompts, models, tools, workflows, API contracts and these guides aligned.
Update `harness.md` after any material change that the project creator or users need to know about. Describe the implemented behavior, workflow and tool boundaries, relevant configuration, verification, and remaining limitations. Keep it accurate to the current code.
Keep the three frontend modules and the four bounded agent folders separate.
Use PydanticAI. Do not add an agent framework or model fallback.
Run local fixture checks. Do not make paid calls or launch cloud training to test changes.
Preserve footage, annotations, model files, credentials and all historical records.
Generate API types after schema changes. Run the documented checks.
